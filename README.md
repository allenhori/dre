# Declarative Reporting Engine (DRE)

A declarative, SQL-driven reporting engine written in Rust: run SQL against any warehouse, template the output (csv, parquet, xlsx, fixed-width, and regulated interchange formats), and deliver it anywhere.

Status: pre-implementation. Planning and specs live in the (private) `project-dre` repo.
